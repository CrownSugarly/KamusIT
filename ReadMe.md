# 📖 KamusIT

Selamat datang di **KamusIT**! Ini adalah proyek sederhana saya untuk mendokumentasikan berbagai istilah di dunia Teknologi Informasi yang sedang saya pelajari.

## 🚀 Tujuan Proyek
- Mencatat istilah IT baru agar mudah diingat.
- Melatih alur kerja Git: `add`, `commit`, dan `push`.
- Belajar menggunakan format Markdown untuk dokumentasi.

## 📚 Daftar Istilah
### 1. Git
Sistem pengontrol versi (*Version Control System*) terdistribusi yang digunakan untuk melacak perubahan pada kode sumber.

### 2. Repository (Repo)
Ruang penyimpanan digital untuk folder atau proyek yang riwayat perubahannya dikelola oleh Git.

### 3. Open Source
Model pengembangan perangkat lunak yang memberikan akses kepada siapa saja untuk melihat, mengubah, dan mendistribusikan kode sumbernya.

### 4. Kernel
Komponen inti dari sistem operasi yang bertugas sebagai jembatan antara perangkat lunak (aplikasi) dan perangkat keras (hardware).
